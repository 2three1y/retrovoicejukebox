Linked and credited only

The classic voices that inspired the jukebox. Their engines are proprietary or have no open license, so they are linked here, not copied.

smoothTalker-sbaitso

  • Repo: joshknnd1982/smoothTalker-sbaitso
  • License: MIT for the NVDA add-on code
  • Why it is not shipped: The real Dr. Sbaitso / First Byte SmoothTalker voice. It works by running the original 1990 DOS engine file under a CPU emulator. That engine is not open source, so it can't be shipped here.

softvoice-sapi5

  • Repo: joshknnd1982/softvoice-sapi5
  • License: MIT for the wrapper code
  • Why it is not shipped: The real 1997 SoftVoice voices for Windows. The engine itself is the original SoftVoice DLL files, which are not open source, so they can't be shipped here.

DECtalk

  • Repo: dectalk/dectalk
  • License: No standard license GitHub can read
  • Why it is not shipped: Modern builds of the classic DECtalk. Linked only.

DECtalkMini

  • Repo: dectalk/DECtalkMini
  • License: No license
  • Why it is not shipped: A portable DECtalk. Linked only.

DECtalk 4.63 source

  • Repo: dectalk/463
  • License: No license
  • Why it is not shipped: Linked only.

Lintalker

  • Repo: dectalk/lintalker
  • License: No license
  • Why it is not shipped: Another synthesizer from the same group. Linked only.

DECTalkApple

  • Repo: masonasons/DECTalkApple
  • License: No license
  • Why it is not shipped: DECtalk as a Mac and iPhone system voice. Linked only.

eSpeak NG

  • Repo: espeak-ng/espeak-ng
  • License: GPL-3.0
  • Why it is not shipped: A great open source engine. Using it would make the whole jukebox GPL, so this version leaves it out. Could be added later as a GPL build.

NVSpeechPlayer

  • Repo: nvaccess/NVSpeechPlayer
  • License: No license file GitHub can read
  • Why it is not shipped: A Klatt-based engine from NV Access. Linked only.

retro-tts-pack

  • Repo: devinprater/retro-tts-pack
  • License: No license
  • Why it is not shipped: Retro synthesizers for Linux. Linked only.

alexclassic

  • Repo: 2three1y/alexclassic
  • License: MIT
  • Why it is not shipped: My own project preserving the classic Mac Alex voice. It has no engine code yet.

Not in the stars

No JavaScript port of SAM (Software Automatic Mouth) is in the starred list, so SAM is not here.
